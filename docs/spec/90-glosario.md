# 90 · Glosario

| Término | Definición |
|---|---|
| **AAIP** | Agencia de Acceso a la Información Pública. Autoridad de control de la Ley 25.326 y responsable del Registro Nacional de Bases de Datos. |
| **Calendario Nacional de Vacunación** | Esquema de vacunas obligatorias y gratuitas definido por el Ministerio de Salud de la Nación, con las edades de aplicación de cada dosis. |
| **Campaña** | Vacunación por tiempo limitado para un rango de edad (por ejemplo, antigripal), cargada por el administrador. |
| **Clasificación técnica** | Interpretación clínica de un indicador (por ejemplo, "talla baja"). Solo la ve el pediatra. |
| **Consulta guiada** | Flujo paso a paso con el que el pediatra registra un control del niño sano en la app. |
| **Control del niño sano** | Consulta pediátrica periódica de seguimiento del crecimiento y el desarrollo, no motivada por una enfermedad. |
| **Cruce de percentiles** | Cambio marcado del percentil de un niño entre dos mediciones consecutivas, que atraviesa varias líneas de percentil. Puede indicar un cambio en su ritmo de crecimiento. |
| **Edad cronológica** | Tiempo transcurrido desde la fecha de nacimiento. |
| **Edad corregida** | En prematuros, la edad cronológica menos las semanas que faltaron para llegar a las 40 de gestación. Permite comparar su crecimiento con el de niños nacidos a término. |
| **Estado del niño** | Nivel que resume la evaluación de un indicador o del conjunto: Dentro de lo esperado, A controlar o Consultar con el pediatra. Orienta, no diagnostica. |
| **Hito del desarrollo** | Habilidad que se espera que un niño adquiera en cierto rango de edad (por ejemplo, sentarse sin apoyo). |
| **IMC** | Índice de masa corporal: peso (kg) dividido por la talla (m) al cuadrado. |
| **Incremento** | Bloque funcional completo que se desarrolla en alrededor de 2 semanas y se muestra funcionando en un encuentro de seguimiento (I1 a I6). |
| **Indicaciones para la familia** | Parte de una consulta que el pediatra escribe para los tutores, que sí la ven. |
| **IODI** | Instrumento de Observación del Desarrollo Infantil, del Ministerio de Salud de la Nación, recomendado para el primer nivel de atención. |
| **LMS** | Método estadístico con el que la OMS publica sus referencias: tres parámetros (L, M, S) por edad y sexo permiten calcular el puntaje Z exacto de cualquier valor. |
| **Longitud / talla** | Estatura medida acostado (longitud, menores de 2 años) o de pie (talla, desde los 2 años). |
| **Matrícula** | Habilitación para ejercer la medicina, otorgada por la Nación (MN) o por una provincia (MP). Su número se repite entre jurisdicciones, por eso se identifica con jurisdicción y número. |
| **Nota aclaratoria** | Texto que el pediatra agrega a una consulta cerrada, fechado y sin modificar el contenido original. |
| **Observaciones** | Parte de una consulta que solo ve el pediatra que la escribió. |
| **Paciente propio** | Niño que un pediatra da de alta en la app sin que su tutor esté registrado. |
| **Pediatra de cabecera** | El pediatra con vínculo activo con un niño. Hay como máximo uno. |
| **Percentil** | Posición de un valor respecto de la población de referencia del mismo sexo y edad: percentil 25 significa que el 25 % de esa población tiene un valor menor. |
| **Perfil finalizado** | Perfil de un niño que cumplió 15 años: se consulta y exporta, pero no admite cargas. |
| **Perímetro cefálico (PC)** | Circunferencia de la cabeza. Se registra hasta los 5 años. |
| **Pesquisa** | Prueba de detección temprana en personas sin síntomas (por ejemplo, audición o displasia de cadera). |
| **Prematuro** | Niño nacido con menos de 37 semanas de gestación. |
| **PRUNAPE** | Prueba Nacional de Pesquisa de trastornos del desarrollo, para menores de 6 años. La aplican profesionales entrenados. |
| **Puntaje Z** | Cantidad de desvíos estándar que separan un valor de la mediana de la referencia. 0 es la mediana. |
| **PVM** | Pendiente de validación médica: regla clínica implementable con valores iniciales pero que debe confirmar un pediatra. |
| **Reclamar un perfil** | Acción del tutor que acepta la invitación de un pediatra y se hace cargo del perfil de un paciente propio. |
| **REFEPS / SISA** | Red Federal de Registros de Profesionales de la Salud, consultable en el Sistema Integrado de Información Sanitaria Argentino. Se usa para validar matrículas. |
| **Registro de controles** | Conjunto de consultas cerradas de un pediatra. Es complementario: no es una historia clínica. |
| **SAP** | Sociedad Argentina de Pediatría. |
| **Semanas de gestación** | Duración del embarazo al momento del nacimiento. 40 semanas es el término. |
| **Tutor** | Madre, padre o representante legal de un niño con cuenta en la app. |
| **Tutor principal** | Tutor que gestiona a los demás tutores y el vínculo con el pediatra. Hay uno por niño. |
| **Vínculo** | Relación entre un niño y un pediatra, que pasa por los estados solicitado, activo y finalizado (o rechazado o cancelado). |
| **Ley 25.326** | Ley de Protección de los Datos Personales. Considera los datos de salud como datos sensibles. |
| **Ley 27.706** | Ley que crea el Programa Federal Único de Informatización y Digitalización de las Historias Clínicas. Pasitos no es una historia clínica y queda fuera de su régimen. |
